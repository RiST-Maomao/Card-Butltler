# バトルライン オンライン（ローカルサーバー版）

2人用ボードゲーム「バトルライン」を、同じLAN内の2人がブラウザから対戦できるようにしたバージョンです。
サーバー（`server.js`）がゲーム状態を管理し、対局中の手札は各プレイヤーのブラウザにしか送られません。

## 遊び方

```bash
cd battle-line-online
npm install
npm start
```

起動すると次のように表示されます。

```
Battle Line online server is running.
  Local:   http://localhost:8080
  Network: http://192.168.x.x:8080   (share this with the other player on your LAN)
```

1. ホスト役が `http://localhost:8080` を開き、「部屋を作る」を押す。表示された4文字の部屋コードをもう一人に伝える。
2. もう一人は同じLAN内の別のPC/スマホから `http://<Networkの欄に出たIP>:8080` を開き、部屋コードを入力して「参加する」を押す。
3. 2人揃うと自動的に対局が始まります。

同じPCの別ブラウザタブ同士でも、ポート番号だけで動作確認できます（本番では2台の端末を推奨）。

## ルール概要

- 6兵科（剣士・弓兵・槍兵・騎兵・盾兵・旗手）×1〜10の部隊カード60枚。
- 戦術カードは17種類の本実装オリジナルから、対局ごとにランダムで10種類（各1枚）が使われる。詳細はアプリ内「遊び方」参照。
- 手番は「確保フェーズ（条件を満たす旗があれば宣言して確保できる）→ドローフェーズ（山札から1枚引く）→プレイフェーズ（手札を1枚使う、無ければパス）」の順。
- 決着済みの旗にはカードを置けない。旗の決着は、両者が既定枚数（通常3枚、泥濘なら4枚）配置した時点で自動判定されるほか、確保フェーズ中に「相手がどう足掻いても追いつけない」ことが証明できれば宣言して先取りできる。
- 戦術カードは、自分の使用済み枚数が相手の使用済み枚数を超えて使うことはできない（＝相手の使用数+1枚まで）。アレクサンダー大王とダリウスは1人につきどちらか1枚まで。
- 1手番の持ち時間は2分。超過すると時間切れ負けになる。双方が「時間を止める」を押している間だけ計測が止まる。
- 9本の軍旗のうち5本、または隣接する3本を確保すると勝利。

## 実装メモ

- `game-engine.js`：ゲームルールと戦術カード効果（サーバーのみで実行される、信頼できる状態）。`node test-engine.js` で主要ルールの簡易回帰テストを実行できる。
- `server.js`：`ws` を使ったWebSocketサーバー兼静的ファイルサーバー。部屋作成・参加・再接続（ブラウザのlocalStorageにトークンを保存）、手番タイマー、一時停止の合意判定を扱う。
- `public/index.html`：クライアント（表示専用。手の正当性は必ずサーバー側で再検証される）。

将来的にインターネット越しの対戦にする場合は、このサーバーを常時稼働するホスティング先（VPSやPaaSなど）にデプロイし、WebSocketの通信をhttps/wss経由にする想定です。
